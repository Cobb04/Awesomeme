# Awesomeme 桌面应用

产品介绍和能力边界见[仓库首页](../README.md)，源码安装、测试与构建见[贡献指南](../CONTRIBUTING.md)。

在仓库根目录安装三个 Adapter 后，再进入本目录安装 `requirements.txt`、构建前端和原生热键组件。应用默认使用独立的 Awesomeme Development 数据目录。
