# 使用 Awesomeme

## 图库与选图

导入后的图片保存在本地图库。可以使用名称和手动标签搜索，将图片放入多个分组，或加入收藏。来源分组用于浏览，不代表实时同步平台当前收藏。

在聊天应用中先点击输入框，再按 ⌘E 呼出面板。可以搜索、使用方向键选择并按回车，或直接点击图片。Esc、再次按 ⌘E 或切换窗口可以收起面板。Mac 当前固定使用 ⌘E，不支持修改快捷键。

选图先复制；目标检查通过时请求一次粘贴，不按发送键。失败时显示复制结果，可以自行按 ⌘V。事件发出不等于目标一定接收成功。

## 各客户端的限制

- 微信可能不公开输入控件、选区或输入法状态。兼容路径核对同一进程和原窗口，但不能识别同一窗口中的所有聊天或光标变化。使用前先明确点击目标输入框。
- 飞书大静态图会生成最长边 120 像素的发送副本。GIF 仅在动画校验通过后缩小；否则保留原尺寸。发送副本不覆盖原图，但缩小会减少放大后的细节。
- 企业微信和飞书保留各自的焦点与选区检查。请先结束中文输入法选词。不同版本、权限状态和多屏环境仍需验证。

基础静态图和动图使用已有开发机实测，不能据此保证所有版本和格式都兼容。

## 来源导入

飞书每轮使用独立扫码登录；结束后清理会话。企业微信读取限定版本的本机客户端。微信通过可选的固定上游 helper 导出，会退出原客户端并使用临时副本，需要完成手机确认；结束后尝试清理并重新打开官方微信。强制结束进程或断电可能中断清理。

下载或校验失败的图片不应计入成功。微信和企业微信可以导入已恢复的部分，界面保留失败计数。飞书与微信的收藏完整性仍有未验证边界。重复导入按内容去重，不因源平台取消收藏而删除本地图。

## 数据与备份

默认开发版目录：

- 配置和原图：`~/Library/Application Support/Awesomeme Development`
- 缩略图与发送副本：`~/Library/Caches/Awesomeme Development`

旧 OhMyMeme 图库不会自动迁移。整库恢复仅适用于空图库；先保留原备份。自动更新关闭，升级通过手动更新源码或后续明确发布的安装包完成。

第一期不向微信、企业微信或飞书的原生表情收藏写入图片，也不迁移聊天记录、联系人或账号登录状态。
